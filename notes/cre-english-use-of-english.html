CRE 公務招聘考試 — Use of English 練習

呢頁係公開溫習資源，唔係個人考試座位或試場通知。實際試場、座位號、到場時間以公務員事務局（CSB）發出嘅官方通告為準。

Use of English 結構（4 部分 × 10 題 = 40 題）

正式考試約 70 分鐘。以下係常見結構同建議時間分配（以當日試卷同 CSB 指引為準）。

部分內容考咩建議時間
1. Comprehension2 篇短文（共 2 頁）主旨、推論、詞義、段落作用25 分鐘
2. Error Identification10 個句子詞彙 / 語法 / 文體揪錯15 分鐘
3. Sentence Completion10 個填空句法結構、間接問句、語序、連接詞20 分鐘
4. Paragraph Improvement短段落 + 問弱點寫作技巧：邏輯、離題、語氣、結構10 分鐘

四大部分點溫（最高回報）

Part 2 揪錯 — 高頻 12 個陷阱

  • 主謂一致：the number of + 複數 → is；a number of + 複數 → are；each / every one of → 單數
  • together with / as well as 不改變主語；either…or / neither…nor 跟最近嗰個
  • the + 複數名詞 + who → who = those who → 動詞用複數
  • by the time + 過去式 → 過去完成式 had done
  • There is/are：不可數 → is；a number of + 複數 → are
  • used to do / be used to doing；look forward to + doing
  • It is essential that + 原形（subjunctive）
  • not that… but that… 對比

Part 3 句子完成 — 高頻結構

  • No sooner…than / Not until + 部分倒裝（had…become）
  • Had + 過去分詞, … would have done（虛擬）
  • the + 比較級, the + 比較級
  • be attributed to / given the cost / provided that / once…had passed
  • ask sb to do / persuade vs force vs remind（語氣）
  • too + adj + for sb + to do

Part 4 段落弱點 — 6 個常見答案類型

  • 論點只有列舉、無發展 → 結論無支撐
  • 意見當事實（In my opinion / everyone knows）
  • 無關細節干擾主旨
  • 前後矛盾（self-contradiction）
  • 結論唔跟上文（logically invalid）
  • 數據誤用（average 受極值影響、統計自相矛盾）

Part 1 閱讀 — 答題重心

  • 主旨題：睇首尾段 + 重複出現嘅概念
  • 推論題：答案一定要完全由原文推導，唔可以自己加常識
  • 詞義題：睇上文代詞 / 破折號 / however / but 附近
  • 段落作用：睇呢段嘅功能（論點 / 例證 / 讓步 / 結論）

考試日 Checklist（通用）

必須帶

  • 身份證（跟 CSB 指引；護照類型以官方通告為準）
  • 座位號（考試通知／座位通知上嘅號碼；唔帶可能延遲入場，損失時間通常唔會補）
  • 自己嘅普通錶 — 淨係得時間同日期，智能手錶不准
  • 文具：HB 鉛筆、擦膠、尺（現場通常唔提供）

禁止 / 唔准帶

  • ❌ 全程用手機（連計時、鬧鐘都唔得）
  • ❌ 智能眼鏡（要按指引存放）；戴眼鏡就要無電子功能嘅普通眼鏡
  • ❌ 計數機等同類工具：若你只考 Use of English，跟當日指引，唔好帶入去最穩陣
  • ❌ 未獲指示前唔可以翻頁、唔可以寫嘢（包括寫座號、身分證號）

當日要做

  • 出門前量體溫；有發燒 / 咳嗽 / 氣促 / 噴嚏 → 建議唔好去
  • 出門前再睇 www.csb.gov.hk/eng/cre.html 有冇臨時更改
  • 天氣差就睇電台 / 電視廣播

實戰時間分配建議（約 70 分鐘）

  • 0–25 分 Part 1 閱讀（兩篇，一篇約 12 分鐘）
  • 25–40 分 Part 2 揪錯（每題約 1.5 分鐘，唔好糾纏）
  • 40–60 分 Part 3 句子完成（最有把握拎分）
  • 60–70 分 Part 4 段落弱點（多用「排除法」，唔好搵唔到就跳）

策略：Part 3 / Part 4 係「技巧題」，練熟就穩拎；Part 1 拉分靠閱讀速度同推理。唔好倒轉次序。
