# kpoleung.com

Public source mirror of [kpoleung.com](https://kpoleung.com) — personal site, Field Notes long articles under `/notes/`, and a small `/lab/` demo.

**Not included:** private memo workspace, BasicAuth configs, deploy secrets, or server infra.

## Layout

| Path | What |
| --- | --- |
| `index.html` | Homepage / digital card |
| `assets/` | Avatars, covers |
| `c/` | NFC contact landing + vCard |
| `notes/` | Public long-form notes (Field Notes Part A/B, CRE mocks, essays) |
| `lab/yolo/` | Browser YOLO lab demo |

## Media

Large Field Notes diagrams and some homepage assets are referenced from the live site (`https://kpoleung.com/...`) so this repo stays lean. Lab YOLO sample images remain in-tree when present under `lab/yolo/assets/samples/`.
